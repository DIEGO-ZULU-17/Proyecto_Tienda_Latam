# 🛒 TiendaLatam — Proyecto de Bases de Datos SQL

Proyecto educativo desarrollado como parte del curso **"Bases de Datos SQL con PostgreSQL"** de [Platzi](https://platzi.com). Modela una tienda de comercio electrónico latinoamericana (**TiendaLatam**) con operaciones en 12 países, y aplica desde la creación del esquema relacional hasta consultas analíticas avanzadas sobre ventas reales.

---

## 🧰 Tecnologías utilizadas

| Herramienta | Uso |
|---|---|
| **PostgreSQL** | Motor de base de datos relacional |
| **pgAdmin** | Gestión visual de la base de datos |
| **SQL** | Lenguaje de consulta y definición de datos |

## 🗄️ Modelo de datos

La base de datos `tiendalatam` está compuesta por **8 tablas relacionadas** siguiendo principios de normalización:

```
paises ──────────┬── sucursales ──┬── empleados
                 │                └── pedidos ──┬── detalles_pedidos
tipos_clientes ──┤                              │
                 └── clientes ────┘             └── productos ── categorias
```

| Tabla | Descripción | Registros |
|---|---|---|
| `paises` | 12 países de Latinoamérica y América Central | 12 |
| `categorias` | 8 categorías de productos | 8 |
| `tipos_clientes` | Clasificación de clientes | — |
| `sucursales` | 20 sucursales en la región | 20 |
| `empleados` | Personal asignado a cada sucursal | — |
| `clientes` | Base de clientes activos | 100 |
| `productos` | Catálogo con precio y stock | 39 |
| `pedidos` | Órdenes de compra realizadas | 200 |
| `detalles_pedidos` | Líneas de producto por pedido | 597 |

### Países cubiertos
Argentina · Chile · Perú · Colombia · México · Brasil · Uruguay · Paraguay · Bolivia · Ecuador · Venezuela · Panamá

### Categorías de productos
Electrónica · Ropa y Calzado · Hogar y Decoración · Alimentación · Deportes y Outdoors · Libros y Educación · Belleza y Cuidado Personal · Juguetes y Entretenimiento

## 📋 Contenido de los scripts SQL

### `02_crear_tablas_tiendalatam.sql` — Esquema DDL
Crea todas las tablas con sus claves primarias (`GENERATED BY DEFAULT AS IDENTITY`), claves foráneas, restricciones `NOT NULL`, valores por defecto y tipos de dato apropiados (`VARCHAR`, `NUMERIC`, `DATE`, `BOOLEAN`, `TEXT`).

### `04_GROUP_BY.sql` — Agregación de datos
- `COUNT`, `SUM` con `GROUP BY`
- Agrupación por cliente y por periodo (año/mes con `EXTRACT`)
- Ranking de clientes con más pedidos

### `05_HAVING.sql` — Filtrado de grupos
- Categorías con más de 5 productos
- Países con más de 10 clientes
- Clientes con más de 3 pedidos
- Países con más de \$50 000 en ventas (`SUM` + `HAVING`)
- Clientes con ticket promedio alto (`AVG` + `HAVING`)

### `06_INNER_JOIN.sql` — Combinación de tablas
- `INNER JOIN` entre pedidos, clientes, sucursales y países
- `LEFT JOIN` para identificar clientes sin pedidos
- Resumen de ventas por categoría combinando 4 tablas
- Cálculo del porcentaje de clientes sin pedidos

### `07_Informe_Ventas.sql` — Proyecto integrador
Reporte analítico completo sobre la operación de TiendaLatam:

| Análisis | Resultado destacado |
|---|---|
| Ventas por país | Argentina lidera, seguido de Perú |
| Ticket promedio por país | Paraguay y Ecuador encabezan la lista |
| Ventas por mes | Los meses pico son diciembre, julio y febrero |
| Top 10 productos | Laptop HP ProBook 450, Tablet iPad Air 10.9, Bicicleta MTB Specialized |
| Categorías > \$10 000 | Electrónica, Hogar y Decoración, Deportes, Ropa y Calzado |
| Dashboard general | 200 pedidos · 100 clientes · 39 productos · 597 líneas de detalle |

## 🚀 Cómo ejecutar el proyecto

> Se requiere tener **PostgreSQL** y **pgAdmin** instalados.

1. Crear la base de datos `tiendalatam` manualmente desde pgAdmin o con:
   ```sql
   CREATE DATABASE tiendalatam;
   ```

2. Ejecutar los scripts en orden:
   ```
   02_crear_tablas_tiendalatam.sql
   02_1_cargar_datos_manual_tiendalatam.sql
   03_consultar_carga_datos.sql
   ```

3. Explorar las consultas analíticas:
   ```
   04_GROUP_BY.sql
   05_HAVING.sql
   06_INNER_JOIN.sql
   07_Informe_Ventas.sql
   ```

> Los archivos CSV en `TiendaLatam_CSV/` pueden importarse como alternativa a la carga manual usando la función **Import/Export** de pgAdmin.

## 🎓 Conceptos aplicados

- Diseño de esquemas relacionales normalizados
- DDL: `CREATE TABLE`, claves primarias y foráneas, restricciones
- DML: `INSERT INTO`, `SELECT`
- Funciones de agregación: `COUNT`, `SUM`, `AVG`
- `GROUP BY` y `HAVING`
- `INNER JOIN` y `LEFT JOIN` entre múltiples tablas
- Funciones de fecha: `EXTRACT`, `TO_CHAR`
- Subconsultas y `UNION ALL`
- Formateo de números con `TO_CHAR` y `ROUND`
